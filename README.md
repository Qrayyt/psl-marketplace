# PSL Marketplace

Каталог промышленных материалов Polymer System Labs.

## Запуск

```bash
docker compose up -d
```

Сервисы:
- **Сайт:** http://localhost:8080
- **Админ-панель:** http://localhost:8080/admin/
- **API:** http://localhost:8080/api/
- **Swagger:** http://localhost:8080/api/docs

## Первый запуск

```bash
# Миграции
docker compose exec app npx prisma migrate deploy

# Сидер (98 товаров + админ + тестовый юзер)
docker compose exec app npx tsx prisma/seed.ts
```

## Учетные записи (сидер)

- Админ: admin@psl.ru / admin123
- Тестовый юзер: user@test.ru / user123

## Стек

- Backend: Node.js + Express + TypeScript + Prisma ORM
- Frontend: HTML + CSS + Vanilla JS
- БД: PostgreSQL 16 + Redis 7
- Инфраструктура: Docker, Nginx

## Структура

```
backend/     - API сервер (Express + TypeScript)
frontend/    - Фронтенд (HTML/CSS/JS)
nginx/       - Конфигурация Nginx
```

### Диалоги клиентов PSL

После деплоя и применения миграций администратор открывает **Админка → Диалоги → Сотрудники**. Сотрудник сначала регистрирует обычный аккаунт на витрине. Администратор назначает роль менеджера по его почте. Менеджер открывает **Профиль → Настройки → Диалоги клиентов** или `/admin/dialogs/`. Менеджеры видят очередь и взятые ими диалоги. Активные диалоги сотрудника возвращаются в очередь при снятии его роли через этот экран.

В Guardex клиент может нажать «Позвать менеджера» либо попросить его в переписке. После входа и подтверждения в очередь передаются последние 40 сообщений. Менеджер берёт карточку из очереди. История, контакты и сводка доступны в рабочем окне. В этом диалоге публичные сообщения пишут клиент и менеджер. Предложения по заметкам доступны сотруднику, принятые заметки хранятся в профиле клиента и видны в следующих назначенных диалогах.

Для генерации сводок и предложений задайте в `backend/.env` `SUPPORT_AI_URL` (полный URL OpenAI-совместимого chat completions), `SUPPORT_AI_MODEL` и, если требуется, `SUPPORT_AI_TOKEN`. Используйте endpoint, которому PSL разрешает обрабатывать переписку. При отсутствии настроек или ошибке модели показываются выдержки из переписки и простые предложения по фактам. Модель используется только для внутренних сводок и заметок в диалогах с менеджером.
