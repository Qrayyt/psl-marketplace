# Galenite Marketplace — responsive ready base

## Структура
- index.html — главная: бренд, каталог, контакты
- product.html — карточка товара
- profile.html — профиль, корзина, избранное
- ai-chat.html — чат с ИИ
- assets/css/styles.css — базовые стили
- assets/css/tablet-style.css — адаптация под планшеты
- assets/css/mobile-style.css — отдельные мобильные стили

## Что уже готово
- 2 карточки в ряд на телефоне
- избранное, корзина, счётчики, тосты
- переход в отдельный товар
- локальное сохранение состояния через localStorage
- отдельная мобильная нижняя навигация

- backend корзины и checkout
