# Galenite Marketplace — ready base

## Что внутри
- `index.html` — главная: бренд сверху, сразу каталог, затем контакты
- `product.html` — отдельная карточка товара
- `profile.html` — профиль, корзина, избранное
- `ai-chat.html` — отдельный AI-чат в light-стиле
- `assets/js/data.js` — локальные данные каталога
- `assets/js/app.js` — логика каталога, корзины, избранного, профиля и демо-чата
- `assets/css/styles.css` — весь UI

## Как открыть
Просто открой `index.html` в браузере.

## Что уже работает
- поиск, сортировка, фильтры по категории и тегам
- переход из карточки в `product.html`
- добавление в корзину и избранное
- локальное сохранение состояния через `localStorage`
- профиль с корзиной и избранным
- AI-чат с отдельной страницей и сохранением истории локально

## Что подключать дальше
1. заменить `assets/js/data.js` на реальные товары/API
2. подключить авторизацию
3. подключить checkout и backend корзины
4. заменить демо-чат на реальный AI endpoint
