Сайт: http://195.133.66.31:8080 (интернет-магазин одежды Galenite)
Наш сервер: 195.133.66.31

Суть: на сайте оформляются заказы. Нужно чтобы они попадали в 1С,
а статусы из 1С возвращались на сайт. Опционально - выгрузка товаров
из 1С в каталог сайта.


======================================================================
1. ДОСТУП К 1С (самое главное)
======================================================================

Нужно получить три строки:

  URL  = ________________________________________________
  Логин = ________________________________________________
  Пароль = ________________________________________________

Подходит любой из вариантов:
  - HTTP-сервис в 1С (если есть свой опубликованный)
  - Стандартный OData (Сервис -> Настройки публикации -> OData)
  - Web-сервис (SOAP)

Если нужен белый список IP - добавить наш: 195.133.66.31


======================================================================
2. КАК МЫ БУДЕМ ПЕРЕДАВАТЬ ЗАКАЗЫ В 1С
======================================================================

Мы будем отправлять JSON вида:

{
  "orderNumber": "PSL-20260410-0001",
  "date": "2026-04-10T15:30:00",
  "customer": {
    "name": "Иванов Иван",
    "email": "ivan@mail.ru",
    "phone": "+79001234567"
  },
  "delivery": {
    "method": "courier",        // courier / pickup / post
    "city": "Москва",
    "address": "ул. Тестовая, д. 1",
    "postalCode": "101000"
  },
  "items": [
    {
      "sku": "ART-001",          // артикул товара
      "name": "Футболка базовая",
      "size": "M",
      "quantity": 2,
      "price": 3490
    }
  ],
  "total": 6980,
  "discount": 500,
  "promoCode": "WELCOME"
}

От 1С нужно:
  - Согласование этого формата (или предложение своего)
  - Куда отправлять (endpoint на стороне 1С)
  - Как идентифицировать товар: по Артикулу? Коду? Другому полю?
  - Что делать если товара или клиента нет в 1С
    (создавать или возвращать ошибку)


======================================================================
3. КАКИЕ СТАТУСЫ ЗАКАЗОВ ИСПОЛЬЗУЮТСЯ В 1С
======================================================================

На сайте используются 5 статусов. Нужно сопоставить с 1С:

  Сайт              1С
  ----              ---
  Новый          = ________________________
  В обработке    = ________________________
  Отправлен      = ________________________
  Доставлен      = ________________________
  Отменён        = ________________________

Мы будем опрашивать 1С каждые 5 минут и спрашивать:
"Какие заказы изменили статус за последнее время?"

Или: 1С сама отправляет нам статус при изменении (если так проще).


======================================================================
4. ВЫГРУЗКА ТОВАРОВ ИЗ 1С (опционально, можно позже)
======================================================================

Если каталог товаров ведётся в 1С - нужна выгрузка в формате JSON.

Поля которые нам нужны на каждый товар:
  - id / артикул (уникальный)
  - Название
  - Цена
  - Категория (группа номенклатуры)
  - Описание
  - Размеры (массив: S, M, L или 39, 40, 41)
  - Цвет
  - Остатки (опционально)
  - Фото (ссылки или base64)

Формат выгрузки - любой удобный (JSON, OData, CommerceML).

Если каталог ведётся вручную на сайте - этот пункт не нужен.
