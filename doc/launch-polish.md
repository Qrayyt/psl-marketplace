# PSL Marketplace — 1.1: единый стиль и подготовка к запуску

## Изменено в ветке
- Один основной навигационный блок на 13 публичных страницах (Каталог, Справочник, Guardex, Профиль, Менеджер).
- Единые типографика, поверхности, фокус, карточки, адаптивное горизонтальное меню.
- Общий неброский UI-слой на четырёх страницах админки, без переписывания бизнес-логики.
- Страница авторизации: меню теперь снаружи узкой карточки.
- Демонстрационный сидер, который удаляет все данные и создаёт тестовые товары, блокируется в production и без явного флага.
- Удалены зашитые в код демо-пароли, введена проверка JWT-секретов в production.
- API, PostgreSQL и Redis публикуются только на 127.0.0.1 сервера.
- Скрипт `npm run check:ui` проверяет статические страницы, меню, стили и скрипты.

## Обязательные проверки до релиза
1. Сверить изображения, цены, фасовки, SKU и документы с каталогом PSL.
2. Проверить 320/375/768/1440 px, iPhone/Android/десктоп: фильтры, каталог, карточку товара, кабинет, вход, справочник и Guardex.
3. Прогнать `npm run check:ui`, тесты API, регистрацию, заказы и админку.
4. На тестовом окружении проверить миграции Prisma, 1C и поддержку/диалоги.
5. Задать реальные уникальные JWT-секреты (от 32 символов), SMTP и пароли БД; проверить вход после рестарта.
6. Проверить бэкап, откат, HTTP статусы, TLS и реальные метрики Lighthouse.
7. Только после приёмки — PR в main, Git-тег `v1.1.0`, выпуск на сервер с smoke-тестами.
