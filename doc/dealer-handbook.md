# Материалы PSL и база знаний

Публичный раздел справочника удалён. Основные разделы сайта: главная с каталогом, профиль с заказами, корзиной и диалогами, чат-бот и админка. Старые `/handbook` и `/handbook/*` перенаправляются на главную. API оглавления возвращает 410. Техкарты в карточках товаров и скачивание PDF сохраняются.

## Что сохранено

`knowledge/handbook/articles.json` содержит 21 перенесённую статью, а `knowledge/handbook/pages/` — три страницы систем со схемами слоёв. Это 24 перенесённых материала, а не все 94 страницы старого Tilda. `knowledge/handbook.sqlite` — готовая SQLite-база этих материалов с полнотекстовым индексом. Исходные структуры, ссылки, пометки о старых редакциях и расхождениях сохранены. Данные находятся вне каталога `frontend` и не выдаются как страницы сайта.

Бот пока не обучен на этой базе. Прежний подбор ссылок на удалённые статьи отключён. Обучение или подключение поиска по базе — отдельный следующий этап. Все записи помечены `requires_review`, чтобы архивные условия и спорные параметры не превратились в подтверждённые рекомендации.

## Выгрузка с PDF на сервере

Установленные ранее 61 PDF и `manifest.json` остаются в `/var/lib/psl/handbook`. Не удаляйте этот каталог: карточки товаров используют файлы из него. Для выгрузки метаданных и текста PDF вместе со статьями:

```bash
cd /opt/psl-marketplace
python3 scripts/export-knowledge.py /var/lib/psl/knowledge.sqlite --documents /var/lib/psl/handbook
```

Скрипт проверяет SHA-256 каждого файла и атомарно заменяет базу только после успешного экспорта. Если доступен `pdftotext` (пакет `poppler-utils`), извлекается текст. Страницы без текста требуют OCR; статус записан в `extraction_status`. Без `pdftotext` сохраняются метаданные и пути к оригиналам со статусом `not_extracted`. PDF не встраиваются в SQLite, оригиналы нужно хранить вместе с базой. Остальные страницы старого хендбука ещё предстоит извлечь из первоисточника.

Для повторной установки PDF из исходных архивов остаётся скрипт `scripts/import-handbook.py`. Том app: `/var/lib/psl/handbook:/var/lib/psl/handbook:ro`.
