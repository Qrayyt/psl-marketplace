# Справочник PSL

Справочник находится по адресу `/handbook/`. Статьи, сертификаты и техкарты доступны без аккаунта. Управление товарами и загрузка документов выполняются через админку.

Справочник содержит обзор систем, FIXTILE Classic и FIXTILE Pro, оглавление отраслей, 15 отраслевых статей и материалы для партнёров. Guardex предлагает ссылки на статьи и использует их краткие описания в ответах по отрасли или условиям работы. Техкарты находятся в карточках товаров. Редакции из архива требуют проверки актуальности.

Действующий канал подачи анкеты на резервирование требует подтверждения PSL. В справочнике есть перечень необходимых сведений и телефон из исходника. Экран успешной отправки старой формы исключён из списка статей. Исходная страница торгового дома содержала ссылки на клиентскую базу и другие рабочие ресурсы. В публичную статью перенесены ссылки на материалы сайта и контакт PSL.

Сверка исходников выявила две разные версии срока проверки статуса резерва, неполную рекомендацию в нефтегазовом разделе и наименование FIXTILE GLS600, которое не найдено в каталоге. Эти данные не используются как подтверждённые рекомендации.

## Установка архива

Перенесите закрытым каналом `PSL_Handbook_Inventory.zip` и семь архивов `PSL_Handbook_Originals_01.zip` — `PSL_Handbook_Originals_07.zip` в один каталог на сервере. Из корня репозитория выполните:

```sh
sudo python3 scripts/import-handbook.py /path/to/archive/PSL_Handbook_Inventory.zip /var/lib/psl/handbook
```

Скрипт сверяет контрольные суммы, объединяет идентичные PDF и устанавливает манифест. При использовании отдельного production Compose добавьте контейнеру app том `/var/lib/psl/handbook:/var/lib/psl/handbook:ro`. Примените миграции в рамках штатного деплоя.

После деплоя откройте справочник и скачайте сертификат и техкарту из карточки товара в приватном окне браузера.
