# Версии и фиксация согласий

Оператор и продавец подтверждён пользователем: ООО «ТД ПОЛИМЕРНЫЕ СИСТЕМЫ», ИНН 9722077344. Реквизиты опубликованы в /seller.html, политике и самостоятельном /consent.html.

Канонический неизменяемый текст версии `2026-11-18-v1`: `backend/src/legal/consent-v1.json`. Публичная страница генерируется `python3 scripts/build-consent-doc.py` из этого источника. При изменении содержания нужно выпустить новую версию, сохранить старый снимок и обновить клиентские payload; не переписывать уже принятую версию.

API регистрации, создания заказа и передачи чата менеджеру требуют `consent: {accepted: true, version: "2026-11-18-v1", purpose: "registration" | "order" | "support"}` с соответствующей эндпоинту целью. Текст, контрольная сумма и время клиента не принимаются в качестве доказательства. Старые клиенты без полей получат 422; при релизе обновить frontend вместе с backend.

Запись `AuditLog` сохраняется в одной PostgreSQL-транзакции с аккаунтом, заказом или обращением. В `details.consent` записываются версия, цель, URL, SHA-256 канонического текста и факт подтверждения; `createdAt` выставляет БД, `ip` берётся из запроса по действующей настройке proxy. В доказательство не копируются пароль, полный текст переписки и контактные данные. Обычный операционный аудит не является криптографически защищённым журналом.

Проверки: `npm run test:consent` (требуются зависимости backend): отсутствие/отказ/неверная цель/устаревшая версия отклоняются до обращения к хранилищу; принятый документ записывается с серверной контрольной суммой; при отказе аудита транзакция откатывается. Для форм: `node tests/consent-forms.cjs` после установки Chromium, или с `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Согласия не разрешают рекламу, распространение данных или обучение ИИ на переписке. Техническое cookie-уведомление не заменяет согласие.

До запуска остаются проверка фактических подрядчиков/размещения данных, регламент сроков хранения и удаления, обработка отзывов и договорные условия продаж. Настройка `SUPPORT_AI_URL` может включать передачу текста внешнему сервису: получателя, основание и маршрут передачи необходимо проверить перед её использованием. Подтверждение оператора само по себе эти вопросы не закрывает.
